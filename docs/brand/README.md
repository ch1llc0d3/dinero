# Macumba brand

dinero's visual identity comes from the talk **"De la macumba y el ocultismo
a la ciencia de datos e IA"** by Cecilia Benitez Montiel (ch1llc0d3), as
given at AI Tinkerers and Women Techmakers. The decks are the reference; this
folder turns them into rules that live next to the code.

| Doc | What it covers |
|---|---|
| [brand-design.md](brand-design.md) | Identity, voice, typography, the slide surfaces, motifs, do / don't |
| [color-palette.md](color-palette.md) | Every colour, its role, measured contrast ratios, usage proportions |
| [../design-system.md](../design-system.md) | How the brand becomes code: token layers, components, theming |
| [palette.html](palette.html) | Live swatches rendered from `css/tokens.css`. Open it in a browser |
